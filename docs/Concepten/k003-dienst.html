K003 - Dienst

Beschrijving​

Diensten zijn specifieke services die door leveranciers of samenwerkingen worden aangeboden op één of meerdere applicaties. Dit betreft het aanbod van verschillende soorten ondersteuning en services rondom software, zoals functioneel beheer, technische ondersteuning, implementatie en training. Diensten vormen de brug tussen leveranciers en organisaties die hun software gebruiken.

Schema Eigenschappen​

naam
required
any
beschrijvingKort
string (Samenvatting) <= 255 characters

Korte beschrijving van de dienst

beschrijvingLang
string <markdown> (Beschrijving) <= 5000 characters

Uitgebreide beschrijving van de dienst

website
string <url> (Website) <= 500 characters

De website waarop meer informatie over dit aanbod te vinden is

status
string
Default: "Concept"

De status van dit aanbod

object (Contactpersoon)

Contactgegevens van een persoon

Array of objects (Modules)

Welke modules worden via de dienst aangeboden

required
object (Organisatie)

Een organisatie die voorzieningen aanbiedt

type
string (Soort dienst)
Enum: "Functioneel beheer" "Applicatiebeheer" "Technisch beheer" "Implementatieondersteuning" "Opleidingen" "Licentiereseller"

Het type dienst dat wordt aangeboden

logo
string <url> (Logo)

URL naar het logo van de dienst

Array of objects (Koppelingen)

Koppelingen die gebruikt worden door deze dienst
